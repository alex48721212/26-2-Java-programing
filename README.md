# 회사 연차관리 시스템 (Leave Management System)

객체지향 프로그래밍 원칙을 적용한 Java 기반 회사 연차관리 콘솔 프로그램입니다.

## 프로젝트 목적

- 직원의 입사일을 기준으로 연차를 자동 계산하고, 신청·승인·차감 과정을 관리한다.
- 핵심 객체(Employee, LeaveRequest, LeaveBalance 등)를 도출하고 역할을 분리하여
  캡슐화, 추상화, 다형성 등 객체지향 설계 원칙을 실습한다.
- 20일간 하루 1회 Git 커밋으로 개발 과정을 기록한다.

## 주요 기능 (예정)

- [ ] 직원 등록 및 조회
- [ ] 입사일 기준 연차 자동 계산
- [ ] 연차 신청 / 취소
- [ ] 팀장 승인 / 반려
- [ ] 잔여 연차 조회
